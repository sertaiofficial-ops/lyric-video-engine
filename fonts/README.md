# Bundled fonts

Free fonts you can use by name in `lyrics.json` or a preset (`"font_emphasis": "bebas-neue"`).

| Name | File | Style | License |
|------|------|-------|---------|
| `bebas-neue` | `bebas-neue/BebasNeue-Regular.ttf` | Condensed all-caps display | [SIL OFL 1.1](bebas-neue/OFL.txt), © 2010 Dharma Type |
| `anton` | `anton/Anton-Regular.ttf` | Heavy condensed display | [SIL OFL 1.1](anton/OFL.txt), © 2020 The Anton Project Authors |
| `montserrat` | `montserrat/Montserrat-SemiBold.ttf` | Clean geometric sans | [SIL OFL 1.1](montserrat/OFL.txt), © 2024 The Montserrat Project Authors |

The SIL Open Font License allows use in videos and redistribution with software, as long as the
license file travels with the font and the fonts are not sold on their own. Sources: the
Google Fonts repository (Bebas Neue, Anton) and the Montserrat project repository.

To use another font, point `font_normal`, `font_emphasis` or a line's `font` at any `.ttf`/`.otf` file.
